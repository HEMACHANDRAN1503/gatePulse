Why Uploading to GitHub Works 100% Now

Previously, files were split into a nested /src folder requiring Node build tools and an external backend server, which caused missing features or blank pages when pushed to GitHub.

This version is packaged into a clean single folder where index.html runs the complete in-memory Rate Limiting Engine directly in the browser!

3-Step GitHub Push:
git init
git add .
git commit -m "feat: Rate Limiting API Gateway (Single-Folder)"
git remote add origin https://github.com/<your-username>/<repo-name>.git
git push -u origin main
To enable free instant hosting on GitHub: go to your repo on GitHub → Settings → Pages → Deploy from branch (main / root). All features, charts, algorithms, and 5+ endpoints will work immediately!
